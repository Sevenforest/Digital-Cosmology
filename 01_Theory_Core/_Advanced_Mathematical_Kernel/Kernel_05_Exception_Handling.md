## 2. Universal Finite-Precision Fluctuations (普遍的な基底丸め揺らぎ)

### 2.1 Headless Universality & Baseline Floor ($P_{\text{base}}$)
有限ビット幅の離散計算機において、量子化・丸め込み境界のエッジ近傍では、完全な決定論的丸めからごく稀に逸脱する **極微小なビット反転・丸め揺らぎ（ソフトエラー）** が物理領域を問わず普遍的に発生する。

$$0 < P_{\text{base}} \ll P_{\text{noise\_floor}}$$

* **非特権の原則:** 宇宙OSのカーネル側に「脳」「生命」「無生物」を識別する特別なプロセスIDは存在しない。恒星内部、大気乱流、高エネルギー衝突点、化学反応系、生物の神経回路のすべてにおいて、同一のハードウェア仕様による基底揺らぎ $P_{\text{base}}$ が作用する。
* **`Kernel_01` (4章) および精密物理実験との整合:** 基底エラー確率 $P_{\text{base}}$ は、孤立量子系・原子時計・加速器実験（LHC等）における観測ノイズ床 $P_{\text{noise\_floor}}$ を十分に下回る極微小値である。したがって、通常の孤立系・平衡系や精密計測では、単発のソフトエラーは統計平均や熱ノイズの中に即座に埋没し、見かけのユニタリ性および決定論的法則が極めて高い精度で保たれる。

### 2.2 Energy Shell Compliance (総エネルギー殻保存の厳守)
このソフトエラーは「無からエネルギーを創造する奇跡」ではない。遷移自体は `Kernel_01` (3.1節) の絶対制約である **エネルギー殻の閉包則 $F(S_E) \subseteq S_E$** の内部で発生する。
すなわち、ソフトエラーによって起きるのは「別の総エネルギー殻 $S_{E'}$ への逸脱」ではなく、**同一の総エネルギー $E = (E_{\text{baryon}} + E_{\text{index}}) + E_{\text{rad}} = \text{const.}$ を保ったまま（必要に応じ局所的な排熱セクタとの極微小なエネルギー再配分を伴い）、量子化境界における遷移先の状態分岐が非決定的に反転する**現象である。

## 3. Amplification via Criticality & Chaos (臨界状態によるマクロ増幅)

基底エラー確率 $P_{\text{base}}$ が全宇宙で極微小かつ一様であるにもかかわらず、なぜ特定の物理系ではそれがマクロな現実の分岐として顕在化するのか。その差を生むのはOS側の特別扱いではなく、**物理系自身が持つ増幅構造の差**である。

### 3.1 Thermal Burial vs. Critical Amplification
任意の領域で生じた単発のソフトエラーは、当初はミクロな未確定状態（ローカルな Dirty State ※`Kernel_04` の広域空間インデックスの Dirty Cache とは別レイヤー）に留まる。

* **熱平衡・安定系（減衰と埋没）:** 多くの安定物質や熱平衡系では、ミクロな1ビットの揺らぎは周囲との相互作用によって即座に平均化・減衰され、マクロな軌道を一切変えずに消滅する。
* **非平衡カオス系・自己組織化臨界系（マクロ増幅）:** 大気乱流や太陽フレアのような強いカオス系、あるいは **自己組織化臨界（Self-Organized Criticality：分岐点ギリギリの不安定状態）** を維持する生物の神経回路網では、単発の極微小な丸め揺らぎが引き金となり、神経発火のカスケード連鎖やマクロな運動出力へと指数関数的に増幅され得る。

### 3.2 Physical Commit & Race Condition (競合と物理的確定)
`Vol.2` (3.2節・5章) のヘッドレス実行原則通り、**意識（Log Reader）自体は物理ログへの直接の書き込み権限（Write Access）を持たない**。ソフトエラーが現実の確定履歴へ組み込まれる過程は、完全にヘッドレスな物理プロセスとして進行する。

* **The Conflict (Race Condition):** 「周囲の熱的・決定論的慣性によるエラー減衰」 vs 「臨界増幅回路によるマクロ相互作用への波及・確定」。

この競合を勝ち抜いて周囲の環境と不可逆な相互作用（**Physical Commit / Write**）を完了した分岐のみが、因果グラフ（DAG）上の変更不能な事実としてマージされる。

### 3.3 Integration via Recall (Read)
意識（`Vol.1`・`Vol.5` の UI層）は、物理的 Commit によって確定済みのログを「想起（Recall）」として事後的に読み出し（Read）、自己の歴史物語へと統合する。我々が「自由意志による選択」として体験するクオリアは、非特権的な宇宙ハードウェアに普遍的に存在する極微小な非決定的揺らぎを、臨界状態にある神経回路がマクロな行動へ増幅・確定したログを、意識層がリアルタイムに近い遅延で解釈した結果である。
